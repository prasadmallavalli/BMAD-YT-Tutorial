- (decision) Paradigm: Layered Architecture (Presentation/BLL/DAL/cross-cutting), adopted from brief.md and addendum.md — not re-derived
- (decision) DbContext lifetime: DbContext-per-operation via a singleton IDbContextFactory<AppDbContext>; repositories/UoW request a short-lived context per business operation via CreateDbContextAsync, disposed immediately after. Prevents stale tracked entities and threading issues in the long-lived WinForms process; supports the async NFR from PRD FR-3.
- (decision) Presentation pattern: pragmatic MVP via constructor-injected Presenter + small per-screen IView interface (e.g. IOrderView) implemented by the Form; Presenter is composition-root-resolved with the IView and BLL services injected. Resolves brief's 'MVP-style separation' and addendum item 6d.
- (decision) OrderStatus transition + Observer trigger: BLL-orchestrated. An OrderStatusService in the BLL holds an explicit allowed-transitions table (resolves PRD Open Question 2's shape, exact table TBD at Epics); after the Unit of Work persists the change it raises the notification via an injected INotifier (plain C# events / small in-process pub-sub). Matches brief's classic layered-enterprise framing, not DDD.
- (decision) DI lifetimes: Scoped-per-business-operation for repositories/UnitOfWork/BLL services, via a manually-created IServiceScope per operation (WinForms has no ASP.NET-style per-request scope). Singleton reserved exclusively for an IAppSettings/configuration accessor — resolves PRD Open Question 4 (Singleton) with a legitimate, non-forced use.
- (decision) Auditing convention: all entities implement IAuditable (CreatedAt, UpdatedAt), stamped via a DbContext.SaveChanges override. No global soft-delete/IsDeleted — Orders use OrderStatus.Cancelled instead of deletion, so soft-delete would be scope without a real use case.
- (decision) Before/After Exhibits (FR-12) live in a dedicated class library project (OrderFlow.Exhibits) with Before/ and After/ folders, compiled independently so violating code never enters the running app's DI graph. Resolves addendum item 6b.
- (decision) Local database: LocalDB for local dev/demo (ships with Visual Studio, zero extra install). Resolves addendum item 6c.
- (decision) Order Processor Factory (FR-15) dispatch: explicit OrderProcessorFactory class wrapping .NET 8 keyed DI services (AddKeyedScoped<IOrderProcessor>(OrderType, ...) + GetRequiredKeyedService). Visible Factory pattern on screen while demonstrating a current .NET 8 DI feature.
- (decision) Overrides brief's .NET 8 pin: target .NET 10 instead. .NET 8 EOLs 2026-11-10 (~3 months from run date 2026-08-06); .NET 10 is current LTS, released 2025-11-11, supported through 2028-11. Same WinForms/EF Core/DI stack, version bump only — surfaced to and confirmed by user before binding.
