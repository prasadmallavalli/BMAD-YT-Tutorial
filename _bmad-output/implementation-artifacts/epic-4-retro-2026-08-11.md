## What Went Well

- **The Story 4.1 design decision held up.** One shared `Program.cs` dispatch entry point (instead of six separate exe projects) let Stories 4.2 and 4.3 extend it additively — two more `case` arms each time, zero rework, zero regressions on the earlier exhibits.
- **"Equivalent output" and "swaps without modification" were proven, not asserted.** Every exhibit pair was verified by actually running it and capturing real console output in the Debug Log — 4.1/4.2's line-for-line output match, 4.3's visible Sql→Fake swap through the same unmodified `CustomerLookupService`.
- **AD-8's isolation boundary held cleanly.** `OrderFlow.Exhibits` never leaked a reference into `Presentation`/`BLL`/`DAL` across three exhibit pairs, confirmed via build success and File List review each time.
- **Story 4.4 (docs-only) got the same rigor as the code stories.** All 26 cited file references verified to exist twice — once before writing, once after.
- **Consistent verification shape across all four stories:** build once, run every exhibit variant (including prior stories' exhibits, as a regression check), run the full test suite. That discipline is why zero regressions slipped through despite the review gate being skipped.
